# 🌟 Hibernate Practice Projects

This repository contains **37 hands-on Hibernate practice modules** designed to help learners **master Java ORM, database interactions, and advanced Hibernate features**.  
Perfect for **freshers & learners** to build strong **backend and database development skills**.

---

## 📝 Modules / Key Features

1. **Core Hibernate Entity Practice** – Entity creation, annotations, mapping.  
2. **Composite ID Practice** – `@Embeddable`, `@EmbeddedId`.  
3. **Date / Timestamp Operations** – `Date`, `Timestamp` usage.  
4. **LOB Handling** – `BLOB` & `CLOB` operations.  
5. **Object Versioning & Concurrency** – `@Version` usage.  
6. **Multiple DB Connections** – Working with multiple data sources.  
7. **HikariCP Connection Pooling** – Efficient DB connection management.  
8. **Primary Key Generators** – Auto & custom generators.  
9. **Bulk Operations** – Batch insert, update, delete.  
10. **HQL Queries** – Select, joins, conditional queries.  
11. **Named Queries** – `@NamedQuery` usage.  
12. **Native SQL Queries** – Execute SQL directly via Hibernate.  
13. **Stored Procedures** – Integration and execution in Hibernate.  
14. **Query By Criteria (QBC)** – Criteria API practice.  
15. **One-to-Many Mapping (Uni & Bi-directional)**  
16. **Many-to-Many Mapping (Uni & Bi-directional)**  
17. **Pagination** – Fetch results in pages.  
18. **Filtering** – Apply dynamic filters.  
19. **Soft Deletion** – Logical deletion using flags.  
20. **Caching** – L1 & L2 caching practices.  
21. **Component Mapping** – `@Embeddable` usage.  
22. **Collection Mapping** – `@ElementCollection` and lists/maps.  
23. **Inheritance Mapping** – `TABLE_PER_CLASS`, `SINGLE_TABLE`, `JOINED`.  
24. **CRUD Operations** – Create, Read, Update, Delete.  
25. **Session Management** – Managing Hibernate sessions effectively.  
26. **Transaction Management** – Commit, rollback, and exception handling.  
27. **Exception Handling** – Hibernate-specific exceptions practice.  
28. **Fetch Strategies** – Eager vs Lazy loading.  
29. **Bidirectional Relationships** – Proper navigation in entities.  
30. **Unidirectional Relationships** – Single-direction entity mapping.  
31. **Cascade Operations** – Save, update, delete cascading.  
32. **Join Fetching** – Optimize queries with joins.  
33. **Embeddable Collections** – Mapping lists, sets inside entities.  
34. **Query Optimization** – Efficient HQL & SQL usage.  
35. **Versioning & Timestamps** – Track entity changes.  
36. **Database Schema Generation** – Auto and manual schema creation.  
37. **Real-time Practice Scenarios** – Combine multiple Hibernate features in examples.
